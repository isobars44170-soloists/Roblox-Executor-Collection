## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled together with a universal loader called xcutorsLoader for convenient access and management.

### Is XCutors free to use?

The xcutorsLoader itself is free and open-source. Individual executors included in the collection may have their own separate licensing or access requirements.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11, both 64-bit editions. A minimum of 4 GB RAM is recommended.

### How do I update the executors?

The xcutorsLoader automatically checks for updates on startup. You can also manually check via the Help menu or download the latest release from GitHub.

### Can I add my own custom scripts?

Yes. Place your .lua files in the designated scripts folder. They will appear in the loader's script library and can be managed from there.

### Why does my anticomponent flag the loader or executors?

Script executors interact with external processes at a low level, which can trigger heuristic-based anticomponent detections. You may need to add an exclusion for the XCutors folder. Always download from the official GitHub repository.

### Which executor should I choose?

Each executor has different strengths. Volt is known for speed, Wave for stability, Potassium for broad script compatibility, and Synapse Z for its extensive API. Try each one to see which fits your workflow best.

### Do I need administrator privileges?

Yes. Running the loader and executors with administrator privileges is required for proper process interaction and script execution.

### Where can I find scripts to use?

There are many community-driven script repositories and forums. XCutors includes a built-in script hub with a selection of popular scripts to get you started.
